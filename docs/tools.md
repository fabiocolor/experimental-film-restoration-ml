# Tools

Two free tools used alongside this research. Each has its own repository, with its own instructions.

- [Faded Balancer](https://github.com/fabiocolor/Faded-Balancer-DCTL): a DCTL for DaVinci Resolve that gives a faded scan a neutral, technical balance before anything else is done to it. It is what balanced the *Candy Candy* scan before it went into Nuke.
- [Advanced Dirt Removal](https://github.com/fabiocolor/Advanced-Dirt-Removal)
