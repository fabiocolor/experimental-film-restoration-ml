# Candy Candy (1976): record

| | |
| --- | --- |
| Source | A 16mm print of the opening titles, faded to magenta, scanned at 4400 × 3300. Balanced with Faded Balancer before Nuke. |
| Reference | A French PAL DVD of the same opening. Both copies cropped to the shared picture area. |
| Route | CopyCat in Nuke, using the published [Nuke template](https://github.com/fabiocolor/custom-machine-learning-for-film-restoration/releases/latest). Separate models for the difficult shots, with four to nine frame pairs each. Only colour is taken from the result; the scan keeps its own luma. |
| Approval | Finished result, presented at FIAT/IFTA 2026. |
| Reproduction | Not yet. The project's Nuke script and the list of frame pairs per model have not been located, so they are not published. The template is the same graph without the shot-specific pairs. |
