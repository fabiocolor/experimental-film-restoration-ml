# Reptilicus trailer, beach shot: tiling test

- **Source:** one faded frame (2048 × 1556) of the *Reptilicus* trailer, from a 35mm trailer reel scan posted on archive.org.
- **Method:** the frame was split into four overlapping tiles. Each tile went through Qwen Image Edit 2511 with the same prompt (Clara Anchor), the softly blurred colour chart and a Canny edge map, and the four results were pasted back at their original positions with hard edges. The same prompt was also run on the whole frame for comparison.
- **What was generated:** colour for each tile. The tiles keep more grain and detail than the whole-frame pass, but the colour drifts between them and the seams show.
