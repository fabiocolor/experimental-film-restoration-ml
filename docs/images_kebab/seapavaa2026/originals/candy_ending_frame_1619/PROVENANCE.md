# Candy Candy, ending: matched-reference colour recovery (single frame)

- **Source:** a faded frame from the ending of *Candy Candy*, balanced before recovery.
- **Reference:** a matching frame from a non-generated copy, used only as colour evidence, not for geometry or brightness.
- **Model and settings:** Qwen Image Edit 2511 (fp8mixed) with the Lightning 4-step LoRA, 4 steps, CFG 0.82, seed 1, a Canny edge map of the source as control.
- **What was generated:** only the colour. The final frame is the source luma with the generated colour (CbCr) on top.
