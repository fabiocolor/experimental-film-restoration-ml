# Qwen Image Edit Colour Recovery Workflow

I've taken down the single-frame workflow that used to be here. It was an earlier version of the research, and this site only offers what I'm using now and can reproduce.

The current route is for pre-balanced footage: one palette still made from the scan's own brightness, with the faded frame as a hint of which hue each object had, carried through the shot and then checked against the colour that survived in the scan. I'll publish it here once a downloadable version reproduces the result I approved. Until then, see [where the research stands]({{ '/research-status/' | relative_url }}).
