Faded colour recovery for balanced scans

The faded colour recovery route for balanced scans (black is black, white is white, the colour has collapsed). One shot at a time, at 768 × 576 for the video model.

Every step was checked against a published shot (record), and the differences are smaller than you can see: average ΔE 0.61 for the palette still, 1.34 for the MiniMax H3 step, 1.20 for the adapter, and the respect step gave identical pixels.

What you need

  • ComfyUI, recent enough to have the MiniMax H3 nodes. Every node in these graphs is a built-in ComfyUI node; no custom nodes.
  • Python 3.10+ with opencv-python, numpy and pillow, and ffmpeg/ffprobe on your path. The adapter step also needs PyTorch with an NVIDIA GPU.
  • Models (put them in the usual ComfyUI folders). These are the exact files used for the check, all public:
    • Palette still:
      • qwen_image_edit_2511_fp8mixed.safetensors (diffusion_models)
      • qwen_2.5_vl_7b_fp8_scaled.safetensors (text_encoders)
      • qwen_image_vae.safetensors (vae)
      • Qwen-Image-Edit-2511-Lightning-4steps-V1.0-bf16.safetensors (loras)
    • Shot:
      • minimax_h3_ref2va_int8_convrot.safetensors (diffusion_models)
      • qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors (text_encoders)
      • minimax_h3_video_vae_fp16.safetensors (vae)
      • minimax_h3_audio_vae_fp32.safetensors (vae)
      • MiniMax-H3-Fun-Controlnet-Union.safetensors (model_patches). Use this original release, not 2.0 or a pruned copy.
    • The NVFP4 text encoder needs an NVIDIA Blackwell GPU (RTX 50-series or newer). On older cards, use the int8_convrot or bf16 encoder from the same repo. These have not been checked against the published result, so compare what you get with the example before you trust it.

The steps

  1. Prepare the shot. python tools/run_step.py prepare --update-hashes --source shot.mkv --out out/prepare Makes the grey carrier video (context.mp4), the edge video (control.mp4) and the palette frame. The carrier is what the video model follows and the edges are what keeps it from moving things. Edit tools/steps/prepare/prep_spec.json first for your shot’s length, the frame to use for the palette and the start of the 124 frames the video model sees.
  2. Palette still. python tools/prepare_still_inputs.py out/prepare/palette_frame.png still, then load graphs/1_palette_still_fp8mixed_ui.json in ComfyUI (laid out, with notes; 1_palette_still_fp8mixed_local.json is the same graph in API format), point the three Load Image nodes at source_y.png, faded_frame.png and canny.png, and run. Then python tools/composite_still.py still/faded_frame.png <graph output>.png palette.png. This still sets the colour of the whole shot, so only go on if you are happy with it.
  3. The shot with MiniMax H3. Load graphs/2_h3_fun_controlnet_ui.json (laid out, with notes on what the step does and what should and should not happen on the footage; 2_h3_fun_controlnet_local.json is the same graph in API format), give it context.mp4, control.mp4 and palette.png (all three reference images), and run. Only the colour should change; the people and the edges should stay exactly where they are. If something has moved, the section needs running again.
  4. Preview. python tools/run_step.py preview --update-hashes --source shot.mkv --carrier out/prepare/context.mp4 --h3 <H3 output>.mp4 --out out/preview Lines the H3 video up with the film and keeps the frames whose brightness matches. Those are the frames the adapter learns from; the ones where the model drifted are left out, so it never learns a mistake.
  5. Temporal CbCr adapter. python tools/run_step.py adapter --update-hashes --source shot.mkv --targets out/preview/teacher_targets.npz --report out/preview/registration_report.json --out out/adapter Learns the colour of this shot from those frames and colours every frame. List your shot’s frames and their hashes (from the preview report) in tools/steps/adapter/adapter_spec.json.
  6. Respect the surviving colour. python tools/run_step.py respect --update-hashes --source shot.mkv --recovered out/adapter/full_recovered.mp4 --out out/respect The red-green colour that survived in the scan can be strengthened but never flipped or weakened. respect.mp4 is the result.

Every frame keeps the scan’s brightness; only the colour is new. Yellow is the dye that fades first, so the yellow-blue choices are an interpretation, and the red-green that survived is evidence.

Example

example/ has the shot the kit was checked against: a 1970s Folgers coffee commercial, 135 frames at 1024 × 768.

The larger example files are hosted outside the repository. Download them into example/ before you start:

  • faded_frame.png
  • result_respect.mp4

  • source_shot.mkv

  • source_shot.mkv: the balanced scan.
  • source_y.png, faded_frame.png, canny.png: the three inputs for the palette graph.
  • palette.png: the published palette still.
  • result_respect.mp4: the published result.

Run the steps on source_shot.mkv and compare your result with result_respect.mp4. Expect small differences: these models don’t give identical output from one run to the next, even at the same seed.

Comfy Cloud (palette still only)

The palette still runs in Comfy Cloud with the same graph. Two versions are provided:

  • graphs/1_palette_still_bf16_cloud_ui.json uses the bf16 model, which is in Cloud’s own library, so it runs without importing anything. In testing its colour differed visibly from the published still (ΔE 2.67), so use it to try the route, not to reproduce the example.
  • graphs/1_palette_still_fp8mixed_ui.json is the published recipe. To run it in Cloud, import qwen_image_edit_2511_fp8mixed.safetensors from Comfy-Org on Hugging Face into your library (Creator plan or higher). The text encoder, the VAE and the Lightning LoRA are already in Cloud’s library.
  1. Open Comfy Cloud and import one of the two graphs.
  2. Upload example/source_y.png, faded_frame.png (from the release, below) and example/canny.png into the three Load Image nodes, in that order, and run.
  3. Both graphs save the raw palette proposal (model_output) and a composite on the source brightness made inside the graph (composite). For the shot, make the palette still with tools/composite_still.py on the model output on your computer; it is the reference composite (the model’s picture scaled back onto the source exactly, with a soft shadow gate) and what the H3 step expects. The in-graph composite is within ΔE 1.4 of it.

The H3 step and the Python steps run locally. Comfy Cloud may need an active plan and credits to run a graph.
